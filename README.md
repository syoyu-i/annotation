# 動画の向きアノテーション

動画の各フレームに `left`（←）または `right`（→）を付けるローカルのデスクトップアプリです。動画を外部に送信しません。対象人物は利用者が目視で判断し、各フレームに1つの向きを付けます。

## 起動

Python 3.10〜3.13を推奨します。WindowsではPython公式インストーラーのTkinterを含む通常の構成を使用してください。**WindowsのPowerShellから起動する方法**が簡単です。

```powershell
cd C:\Users\tetsuya\app\annotation
py -m venv .venv-win
.\.venv-win\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-win\Scripts\python.exe app.py
```

2回目以降は最後のコマンドだけで起動します。PowerShellの実行ポリシー変更や仮想環境のactivateは不要です。

Linux / macOSの場合：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

LinuxではTkinter・venvとGUI表示環境が必要です。Ubuntuなら必要に応じて `sudo apt install python3-tk python3-venv` を実行します。WSLではWSLg等のGUI環境が必要です。WindowsとWSLでは仮想環境を共有しないでください。PyAVの配布wheelを使う場合、FFmpegの別途インストールは不要です。

## 操作

1. 「動画を開く」で動画を選びます。実際に全フレームをデコードして、FPS・フレーム数・各フレームの表示時刻を確認します。長い動画は読み込みに時間がかかります。全画像をメモリへ保存する方式ではありません。
2. 現在のフレームの向きに合わせて **← または →** を押します。離すと確定して次のフレームへ進みます。画面の「← 左」「→ 右」ボタンも同じ1フレーム操作です。
3. 同じ向きが続く場合は、**矢印キーを押したまま W** で区間を1フレーム延長します。**Q** で1フレーム短縮します。Q/Wは長押しもできます。編集中は区間の最後のフレームを動画に表示し、矢印キーを離すと区間の次へ進みます。
4. 矢印キーを押していないときの **Q / W** は、ラベルを変えずに前後へ1フレーム移動します。画面のコマ送りボタン、タイムラインのクリックでも移動できます。
5. **Ctrl+Z** または「元に戻す」で前の編集を取り消します。矢印キーの押下から解放までが1回の編集です。押している途中ならその編集中の区間を取り消します。
6. 全フレームにラベルが付くと「完了・CSVと円グラフを出力」が有効になります。編集中の矢印キーを離し、保存先を選択します。

タイムラインの青は左、橙は右、灰は未入力です。黒線が現在のフレーム、黒枠が編集中の区間です。フレームごとのセルは等幅で、可変フレームレートの場合も1セル＝1フレームです。横スクロールで全体を移動でき、編集位置には自動追従します。

区間は開始位置から右方向に伸びます。最短は1フレームで、動画の末尾より先には伸びません。短縮時はその部分の元のラベル（未入力を含む）を復元します。既存ラベルは上書きでき、Ctrl+Zで復元できます。矢印単独の長押しは勝手に区間を延長しません。

## 出力

保存先を `sample_labels.csv` にすると、同じ場所に `sample_labels.svg` も保存します。SVGはブラウザで開ける円グラフです。

| CSV列 | 内容 |
| --- | --- |
| `frame_index` | 0始まりのフレーム番号（画面上の番号は1始まり） |
| `time_seconds` | 最初の表示フレームを0秒とした実際の表示時刻 |
| `duration_seconds` | 次のフレームまでの時間。最終フレームは動画のduration情報、なければ平均FPS、直前のフレーム間隔の順で推定。それらもない1枚だけの動画は0 |
| `label` | `left` または `right` |

小数は標準で9桁、文字コードはExcelで開きやすいUTF-8 BOM付きです。円グラフは**フレーム数ベース**で左右の件数・割合を示します。可変フレームレートの場合、時間ベースの割合とは異なることがあります。

フレームの時刻はFPSから一律計算せず、動画のPTS（表示時刻）を使用します。FPSは動画の平均レート情報を表示します。時刻情報がない、重複・逆転する、デコードできない動画は読み込みエラーにします。対象は先頭の動画ストリームです。対応形式はPyAV/FFmpegでデコードできる動画（MP4、MOVなど）です。

最小構成のため、途中保存・再読み込み・自動判定・音声再生・人物ごとの別ラベルはありません。終了や動画の変更でメモリ上の編集内容は失われるため、未出力なら確認ダイアログを表示します。

## 設定とコードの説明

細かい変更はまず **`config.py`** を編集し、アプリを再起動してください。

| 設定 | 初期値 | 用途 |
| --- | --- | --- |
| `EXTEND_KEY` / `SHRINK_KEY` | `w` / `q` | 区間の伸縮・コマ送り。異なる英小文字を指定 |
| `FRAME_WIDTH` | `10` | タイムラインの1フレーム幅。正のpx値 |
| `TIMELINE_HEIGHT` | `110` | タイムラインの高さ（110以上を推奨） |
| `WINDOW_SIZE` | `1120x820` | 初期ウィンドウサイズ |
| `COLORS` | 灰・青・橙 | 未入力・左・右の表示色と円グラフの色 |
| `TIME_DECIMALS` | `9` | CSVの秒数の小数桁数 |
| `CSV_ENCODING` | `utf-8-sig` | CSVの文字コード |

長押しのリピート速度はOSのキーボード設定に従います。入力には半角英数を使用してください。

| ファイル | 役割 |
| --- | --- |
| `app.py` | Tkinterの画面、キー入力、動画読み込みスレッド、タイムライン描画、保存ダイアログ |
| `annotation_model.py` | ラベル配列、編集区間の伸縮、確定、差分履歴によるUndo。UIから独立 |
| `video.py` | PyAVによるフレーム時刻一覧の作成と正確なフレーム読み出し |
| `export.py` | 1フレーム1行のCSV、左右の件数を示すSVG円グラフ |
| `config.py` | キー・表示・出力パラメータ |
| `tests/` | 区間編集・Undo・出力、生成した実動画での時刻・シーク検証 |

`Annotation.begin()` で最初の1フレームを編集し、`resize()` が変更前の値を保持しながら区間を伸縮、`commit()` が履歴を1件作成します。`undo()` は値と編集開始位置を復元します。全フレームに対するラベル配列と、変更箇所だけを持つUndo履歴を保持します。

`scan()` は表示順で全フレームを調べ、浮動小数点の累積誤差を避けるため内部の時刻を有理数で保持します。`VideoReader.read()` は連続したコマ送りではそのままデコードし、離れたフレームへは直前のキーフレームから目的のPTSまでデコードします。シーク後に目的のフレームが見つからなければ先頭から読み直します。長いGOPの動画では逆方向のコマ送りに時間がかかることがあります。

PyAVの仕様参照：[フレームのPTS](https://pyav.org/docs/stable/api/frame.html)、[シークとデコード](https://pyav.org/docs/stable/api/container.html)。

## 検証

```powershell
.\.venv-win\Scripts\python.exe -m unittest discover -s tests -v
```

Linuxでは `.venv/bin/python -m unittest discover -s tests -v`。動画テストは一時フォルダに小さな動画を生成し、終了時に削除します。

GUI表示環境がある場合は `.venv/bin/python -m unittest discover -s tests -p gui_smoke.py -v` で、キー入力処理・完了ボタン・ファイル出力をつなぐ結合テストも実行できます。WindowsではPythonのパスを `.\.venv-win\Scripts\python.exe` に置き換えてください。

開発時はPython 3.10、PyAV 16.1.0、Pillow 12.3.0で通常の6テストとGUIの1テストが成功しています。Windows実機での物理キーの長押し操作は、上記の手動手順で確認してください。

手動では短い動画を開き、←を押しながらWを数回、Qで短縮、解放、Ctrl+Zを順に試してください。動画の表示位置と色が一致すること、全フレーム入力前は完了ボタンが無効なこと、全入力後のCSV行数がフレーム数と一致することを確認できます。
